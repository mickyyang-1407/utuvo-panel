# 0009 — 「時間走秒」00 點把小時吃掉（00:35:17 顯示成 35:17）

- 票型：mechanical（orchestrator 親修，≤20 行）｜ Micky 09-22 00:35 截圖回報「bug，00點不會顯示」

## 根因

走秒時鐘是一整天的系統計時器 `Text(timerInterval: 今天0點…24點, showsHours: true)`。系統格式在不滿 1 小時時省略小時（00:35:17 → "35:17"），1–9 點不補零（"1:05:03"）。

## 修法

計時器照舊（實機一直會跳）；前面補一段靜態字 `ClockPrefix.forTime(hour:minute:)`：10 點以後空字串、1–9 點 "0"、0 點 "00:"（分鐘 <10 再補 "0"）。前綴只在分鐘邊界變，小工具本來就一分鐘一個 entry。

## 驗收

- Check：8 個時間點（00:35:17、00:05:03、00:00:00、00:59:59、01:05:03、09:59:59、10:00:00、23:59:59）前綴＋系統格式＝HH:MM:SS；突變（0 點不補）→ 4 FAIL、exit 1。
- UI test12（新）：app 內打開走秒 → 桌面小工具相鄰文字合起來必須是 `HH:MM:SS`（兩位數小時）。舊 bug 只有 "35:17" 一段，會紅。**passed**。
- sim 00:56 實拍 `00:56:02`（`docs/evidence-1.0.1/0009-sim-clock-00-hour-kept.png`）。
- 走過的死路（記錄用）：①每分鐘計時器＋超寬 frame 右靠裁切 → WidgetKit 把超出提議的 frame 畫成空白；②`.timer(countingUpIn:maxFieldCount:1)` → 會拼成「14 seconds」；③遮罩＋位移 → 可畫但看起來換 entry 後凍結。
- ⚠️ 模擬器桌面閒置時會暫停小工具即時文字（原本的整天計時器也一樣凍住，點一下面板就恢復）；這是模擬器行為，實機一直會跳（Micky 截圖為證）。
