## 新功能（What's New）

**zh-Hant**
- 修正：第一次安裝後，小工具可能一直停在灰色的空白外框、不顯示內容（網路慢或尚未允許網路時特別明顯）。現在會先顯示時間、行事曆等內容，天氣等網路恢復後自動補上。
- 打開 app 時會順便更新天氣，小工具第一次出現就有資料。

**en-US**
- Fixed: after a fresh install the widget could stay on an empty grey outline instead of showing your panel — most often on a slow network or before network access was allowed. It now shows the time, calendar and the rest right away, and fills in the weather once the network is back.
- Opening the app now refreshes the weather, so the widget has data the first time it appears.

1. Archive 1.0.2 (7) → `env PATH=/usr/bin:/bin:/usr/sbin:/sbin xcodebuild -exportArchive`（`ExportOptions-AppStore.plist`）→ `xcrun altool --upload-app --apiKey --apiIssuer`。
2. ASC：建 1.0.2 版本 → 等 build 7 處理完 → 掛 build → PATCH whatsNew（兩語系）→ 審核備註沿用 1.0.1 → `reviewSubmissions` 送審。
3. IPA 放 `~/Desktop/utuvo builds/UTUVO-Panel-1.0.2-7/`，SHA256SUMS 同步，舊版 1.0.1-6 依規則處理。
